Origin and license

Original synthetic geometry and specifications authored for a redistributable benchmark. The dataset and generated evidence are dedicated under CC0 1.0.

Method

The native STEP was written from a solid assembly and read back with OpenCascade STEPCAF/XDE. The shared engineering pipeline traversed placed occurrences, measured world-coordinate bounds, matched exact part labels to the source specification and multiplied quantities by the specified loss per item.

Verification scope

This benchmark checks CAD hierarchy, occurrence placement, quantity reconciliation and the loss arithmetic. The specified losses are synthetic inputs. A temperature-rise test would need a characterized enclosure, installation conditions and validated losses.
